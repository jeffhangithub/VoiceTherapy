# 产品决策记录

更新日期：2026-09-01

## 已确认

- 手机端：iPhone。
- 车载场景：通过车载蓝牙进行双向语音会谈。
- 常驻主机：Mac mini 长期开机运行。
- Agent：Hermes Agent 负责咨询对话、工具调用和知识库检索。
- Obsidian Vault：`Jeff`。
- 允许检索的知识目录：
  - `raw/咨询纪要/心理咨询录音文字稿`
  - `concepts/therapy`
- 数据权限：允许读取原始文字稿与会谈分析。
- 原始音频：不保存。
- 会谈逐字稿：保存。
- 会谈摘要：保存。
- 代码托管：[jeffhangithub/VoiceTherapy](https://github.com/jeffhangithub/VoiceTherapy)。

## 当前待选

- 主语音识别服务（STT）与备用服务。
- 主语音合成服务（TTS）与备用服务。
- 咨询师音色：偏女性、偏男性或中性；以及温暖程度和语速。
- 手机远程连接方式：优先测试私有组网；如安装成本不可接受，再使用公网 HTTPS。

## 设计边界

- 不采用供应商自带的端到端“语音大模型”代替 Hermes。语音服务只负责 STT/TTS，确保咨询逻辑、Obsidian 检索、记忆和安全规则仍由 Hermes 控制。
- 浏览器不接触 Hermes API 密钥；所有请求经 Mac mini 上的 Voice Gateway 转发。
- 原始音频只在内存中分片处理，正常流程不写磁盘；异常日志也不得包含音频载荷。
- 知识库第一阶段只读；逐字稿和摘要写入单独输出目录，不修改既有咨询档案。
- 驾驶模式默认减少屏幕交互，支持打断播报，并避免要求用户阅读或操作复杂界面。
- 这是一项辅助反思工具，不冒充持证治疗师，不进行诊断；危机语句触发安全回应和现实世界求助指引。
